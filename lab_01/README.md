# Лабораторная работа 1. Консольный набор утилит

Python-пакет `toolkit` с консольным интерфейсом (CLI). Внутри два инструмента:

- **калькулятор** арифметических выражений;
- **конвертер величин** (длина, масса, температура).

Проект написан только на стандартной библиотеке Python. Сторонние пакеты не нужны. Функции `eval`, `exec` и `ast.literal_eval` не используются: выражения разбираются собственным токенизатором, а вычисляются через обратную польскую запись.

## Возможности

### Калькулятор

- целые и вещественные числа (`3`, `2.5`);
- операторы `+`, `-`, `*`, `/`, а также `//` (целочисленное деление) и `%` (остаток);
- скобки и вложенные скобки;
- приоритет `*`, `/`, `//`, `%` выше, чем у `+`, `-`; операторы одного приоритета выполняются слева направо;
- унарные `+` и `-` (`-5`, `2 * -3`, `-(2 + 3)`);
- пробелы между токенами игнорируются.

Вычисление идёт в три этапа, каждый находится в отдельной функции:

1. **токенизация**: строка превращается в список токенов;
2. **валидация**: проверка порядка токенов и скобок;
3. **вычисление**: перевод в обратную польскую запись (алгоритм сортировочной станции) и расчёт по стеку.

Вычислительное ядро не использует `input()` и `print()`: результат возвращается из функций, а печатает его только CLI.

### Конвертер

| Группа | Единицы |
|---|---|
| длина | `mm`, `cm`, `m`, `km` |
| масса | `g`, `kg`, `cn` (центнер, 100 кг), `tn` (тонна, 1000 кг) |
| температура | `c` (Цельсий), `f` (Фаренгейт), `k` (Кельвин) |

Правила:

- регистр единиц не учитывается (`KM`, `Km`, `km` одно и то же);
- конвертация между разными группами запрещена (например, `km` в `kg`);
- температура ниже абсолютного нуля запрещена (`-273.15 °C`, `-459.67 °F`, `0 K`); само значение абсолютного нуля допустимо;
- результат всегда возвращается как `float`.

## Команды

```text
python -m toolkit calc "EXPRESSION"
python -m toolkit convert VALUE --from UNIT --to UNIT
python -m toolkit --help
```

Примеры:

```text
$ python -m toolkit calc "2 * (3 + 4) - 5"
9.0

$ python -m toolkit calc "-(2 + 3)"
-5.0

$ python -m toolkit calc "7 // 2"
3.0

$ python -m toolkit convert 5 --from km --to cm
500000.0

$ python -m toolkit convert 100 --from C --to K
373.15
```

Выражение для `calc` нужно заключать в кавычки, иначе оболочка может разбить его на несколько аргументов или обработать скобки сама.
## Структура проекта

```text
lab_01/
  pyproject.toml
  README.md
  src/toolkit/
    __init__.py
    __main__.py        # CLI (argparse), вывод, коды выхода
    calculator.py      # токенизация, валидация, вычисление
    converter.py       # конвертер величин
    errors.py          # собственные исключения
    constants.py       # операторы, единицы, коэффициенты
  tests/
    test_calculator.py
    test_converter.py
    test_cli.py
```

Исключения: базовый `ToolkitError`, от него наследуются `CalcError` и `ConvertError`. CLI ловит `ToolkitError` и превращает его в сообщение в stderr с кодом `2`.

## Установка с GitHub

Нужны Python 3.9 или новее и Git.

1. Клонировать репозиторий и перейти в папку проекта:

```text
git clone <ссылка-на-репозиторий>
cd <папка-репозитория>/lab_01
```

Если `lab_01` является корнем репозитория, достаточно `cd <папка-репозитория>`.

2. Проверить версию Python:

```text
python --version
```

В некоторых системах команда называется `python3`.

3. Запустить проект одним из способов.

**Способ 1: без установки (подходит всегда).** Указать Python папку с пакетом.

Windows (PowerShell):

```text
$env:PYTHONPATH="src"
python -m toolkit --help
```

Windows (cmd):

```text
set PYTHONPATH=src
python -m toolkit --help
```

Linux и macOS:

```text
PYTHONPATH=src python3 -m toolkit --help
```

Переменная `PYTHONPATH` действует только в текущем окне терминала. Альтернатива: перейти в папку `src` и запускать команды оттуда (`cd src`, затем `python -m toolkit --help`).

## Тесты

Тесты написаны на стандартном модуле `unittest`, дополнительные пакеты не нужны. Каждый тестовый файл сам добавляет папку `src` в путь поиска модулей, поэтому ни установка, ни `PYTHONPATH` для тестов не требуются.

Запуск из папки `lab_01`:

```text
python -m unittest discover -s tests -v
```
